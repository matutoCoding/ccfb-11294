# 霓虹灯牌设计预览系统（Neon Sign Studio）

浏览器内完成霓虹灯牌的文字/SVG 排管、工艺校验、夜景效果预览与报价，数据全部保存在本地。

## 技术栈

Vite + React 18 + TypeScript + three.js（原生 API，几何管线命令式精确控制）+ Zustand + opentype.js + svg-path-properties

## 启动

```bash
npm install
npm run dev        # 开发，默认 http://127.0.0.1:5180
npm run build      # 生产构建
npm test           # 几何/排管/SVG 全部单元与端到端测试（26 项）
```

| 页面 | 功能 |
| --- | --- |
| 订单列表 | 订单增删改、复制、JSON 导入导出（localStorage 持久化） |
| 灯管排线 | 文字/TTF/SVG 输入 → 自动沿笔画排管；颜色、管径、动画、接触不良管段；2D 俯视 + 3D 联动 |

## 核心工艺约束如何保证（重点）

### 1. 弯管半径不小于设定值

`src/lib/fillet.ts` 的 `applyMinBendRadius`：

1. **Douglas-Peucker 抽稀**（容差 1.5mm）把等弧长采样折线还原为特征折线——弯管机只在特征点弯折，采样噪声不产生伪转角。
2. 每个真实转角按 `s = r·tan(δ/2)` 计算所需切线长，两层硬约束：
   - 相邻转角共享边的切线长之和 ≤ 边长（迭代松弛）；
   - 单切线长 ≤ 邻边长度的一半（切线点不得越过边中点，防止路径折叠）。
3. 约束无法满足时按**可达到的最大半径**降级并逐条告警；邻边 <1mm 的转角保留硬折点并提示简化设计——对应真实工艺反馈，而不是静默生成不可制造的路径。
4. 输出前做自交保护：圆角结果若引入交叉，自动回退到简化折线。

### 2. 路径不自交

`findSelfIntersections` 用空间哈希做 O(n) 检测，并针对霓虹字形的三类误报做了区分：

- 近共线边（夹角 <0.006°）不判交叉；
- 近平行边（<5°）且中心线间距 <3mm（约半个管径）判为近接触而非交叉；
- 交点距端点 <3mm 判为发夹弯/电极连接；
- 真正的大角度交叉（如蝴蝶结）正常报硬错误。

### 3. 夜景辉光旋转不闪不糊、60fps

- 管体 = 外层物理玻璃（MeshPhysicalMaterial 透射）+ 内层气体发光管（自定义 ShaderMaterial，加色混合）；
- 辉光 = UnrealBloomPass（半/三分之一分辨率缓冲可调）+ 沿管分布的径向渐变精灵做墙面溢散；
- 动画强度函数 JS/GLSL 同源（`src/three/intensity.ts`），点光源与管体严格同步；
- 点光源限 4 个（最长的 4 根管）、像素比上限 1.5、Bloom 分辨率可调；夜景页实时显示 FPS。

### 4. 动画模式

常亮 / 闪烁 / 流水（沿弧长行进波）/ 接触不良（可指定弧长百分比区间，只让该段随机灭灯），每根灯管独立设置，全局速度统一调控。

## 报价模型

- 灯管负载按 60W/m 估算，变压器功率 = 负载 × 冗余系数（默认 1.25），向上取整到常见规格；
- 报价 = 灯管（元/m）+ 变压器（元/W）+ 背板（元/m²）+ 固定费用，单价均可调；
- 截图可选叠加订单号、背板尺寸、管径、气体颜色、变压器功率与报价。

## 中文字体

内置 Monoton / Bebas Neue 两款拉丁展示字体（首次使用从 CDN 加载 TTF）。中文在「设置」页上传本地 TTF/OTF，以 base64 持久化在浏览器，离线可用。
